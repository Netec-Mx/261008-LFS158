# Introducción a Kubernetes

Curso introductorio basado en Linux Foundation LFS158 para comprender el origen, arquitectura y bloques fundamentales de Kubernetes; crear un clúster local con Minikube; acceder al entorno; desplegar aplicaciones y utilizar Services, almacenamiento, ConfigMaps, Secrets e Ingress.

## Accesos rápidos

- [**Setup Guide del curso**](https://github.com/Netec-Mx/261008-LFS158/blob/main/SETUP_GUIDE.md)
- [Laboratorios por capítulo](#lista-de-laboratorios)

## Estructura

- `SETUP_GUIDE.md`: guía de instalación y preparación del entorno.
- `CapituloXX/README.md`: guía de laboratorio por capítulo.
